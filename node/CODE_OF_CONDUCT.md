# Code of conduct

We adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as our code of conduct.

In short: be respectful, argue about the mathematics and the code, not the person, and assume good faith. Harassment, personal attacks, and publishing someone's private information are not tolerated, here or anywhere the project is represented.

Machine-generated volume is a burden on human reviewers. Contributions that go upstream, to Mathlib or elsewhere, follow that community's review norms and arrive refactored and documented, never as raw machine output.

Report conduct concerns to **conduct@counterbank.cc**. Reports are handled in confidence.
